# SentimentSphere

**Multimodal Emotion Recognition Web App**

SentimentSphere is an advanced web application designed to recognize and analyze human emotions using both textual and visual data. By leveraging state-of-the-art machine learning techniques, the app provides insights into sentiment and emotion from multiple sources, enhancing user experience and understanding of emotional context.

## Features

- **Multimodal Emotion Recognition:** Analyze both text and visual (image/video) data to detect emotions.
- **State-of-the-art Models:** Utilizes modern NLP and Computer Vision techniques.
- **User-friendly Web App:** Designed for easy interaction and exploration of results.

---

## Concepts & Technologies

- **Natural Language Processing (NLP):** For analyzing and classifying emotions from text.
- **Computer Vision:** For recognizing emotions in visual data.
- **Deep Learning:** Utilized for both text and image-based emotion recognition.
- **Python & Jupyter Notebooks:** Main languages and tools for prototyping and development.
- **Dependency Management:** All requirements are listed in `requirements.txt`.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/Shivam2Goyal/SentimentSphere.git
    cd SentimentSphere
    ```
2. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
3. (Optional) Use the dev container setup for a reproducible development environment.
